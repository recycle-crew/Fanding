# 方鼎庫存系統規劃與客戶展示

繁體中文、天藍色系的靜態網站，包含 HIS／OTC 功能規劃、假資料操作 Demo，以及畫面規劃與流程示範。

## 開啟方式

直接用瀏覽器開啟 [index.html](index.html)，不需要安裝套件或執行建置。

- [規劃文件](index.html)：系統分工、五個功能模組與待確認問題。
- [系統 Demo](demo.html)：展示登入、廠商維護、HIS 藥品修改、OTC 入出庫／領用與盤點。
- [畫面規劃板](board.html)：7 個分類、22 個 Frame，可縮放、拖動畫布、逐步示範及直接操作。

Demo 可使用預填的展示帳號登入；全部資料保留在記憶體中，重新整理即重置。規劃板的互動視窗共用當次假資料，縮圖則是獨立的初始畫面參考。

## 展示範圍

本專案未串接 NAS LDAP、HIS、正式 API 或資料庫。領用立即扣庫及 HIS 盤點直接調整，均為標示在畫面上的展示假設，正式作業規則仍待確認。

請勿輸入真實帳密或客戶資料。所有品項與廠商均為虛構展示資料。
